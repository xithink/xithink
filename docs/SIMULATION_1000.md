## 结果摘要

- **零经历**：三种 profile 都没有经验规则，符号准确率为 0；对缺少条件的测试能够 100% 停手，不会猜结论。
- **10岁 / 250次经历**：探索型已验证 6 条条件规则并达到 100% 留出符号准确率；平衡型和谨慎型各验证 5 条，准确率 83.3%。
- **20岁 / 500次经历**：平衡型达到 6 条活动条件规则与 100% 准确率；谨慎型仍保留 5 条、83.3%，体现更高接受门槛。
- **40岁 / 1000次经历**：三种 profile 都形成 6 条活动条件规则，在当前合成测试集上达到 100% 准确率、100% 条件不足时停手、0% 双向冲突。
- **规则家谱**：随着证据批次增长，家谱持续追加修订节点，而不是覆盖历史；40岁阶段约 315–320 个谱系节点，最大修订代数 42。
- **主动验证**：系统在形成相反条件理论后生成验证请求，模拟器使用独立 Oracle 执行；生产路径只会提出观察需求，不会自造证据。

## 首轮 1000 次模拟暴露并修复的问题

0.6 条件规则只有在 `counterexamples == 0` 时才会 verified。含 6% 噪声的长期经历几乎必然出现例外，所以首轮 1000 次模拟中所有规则都停留在 provisional，符号准确率为 0。

0.7 改为：

```text
support >= min_support
AND confidence >= verification_confidence
AND counterexample_rate <= max_counterexample_rate
```

平衡型默认 `condition_max_counterexample_rate = 0.12`；谨慎型 0.07；探索型 0.18。明确反例不会被删除，它们仍保留在规则证据与家谱中，并降低规则置信度。

## 当前测试世界的限制

这是一套用于验证认知架构的**合成符号世界**，隐藏规律以条件化三段关系为主。100% 结果只说明当前程序成功学习了这套已知隐藏结构，不能解释为“达到人类40岁认知能力”。后续应增加时间条件、数字阈值、因果干预、遗忘、社会经验和跨领域任务。
