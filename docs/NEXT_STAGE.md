# XThink 0.8 Next Stage

0.7 已经具备：

```text
形成规则
→ 规则家谱
→ 正反理论
→ 主动选择验证条件
→ 年龄/经历模拟
```

0.8 建议进入更复杂的“理论检验”层：

1. **Counterfactual Engine**：`如果条件 A 不存在，会怎样？`，与现实 Fact Memory 完全隔离。
2. **Temporal Rule Evolution**：支持短期/长期不同结果，时间进入规则条件。
3. **Numeric Threshold Discovery**：从经验发现 `temperature > T -> failure`。
4. **Causal Intervention Boundary**：区分观察相关与真正干预结果。
5. **Forgetting / Memory Consolidation**：年龄模拟加入遗忘、重复强化和睡眠式记忆整理，而不是无限累积全部 episode。
6. **Social Experience / Perspective Model**：区分“我经历过”“别人报告过”“群体共识”，并给不同 provenance 权限。
7. **Life-course benchmark v2**：把当前合成三元规则世界扩展成多领域、多时间尺度、多冲突源测试集。
